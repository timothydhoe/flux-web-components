# Data table

<FluxComponentMetaData id="data-visualisation-data-table" />

## Doel

Gebruik de `data-table` component om de cijfers van de grafiek in een tabel te tonen, onder "Bekijk de cijfers". De
tabel is het tekstalternatief van de grafiek. Dezelfde cijfers kan je ook downloaden als CSV.

Elke [data-figure](/docs/data-visualisation-data-figure--documentatie) toont de tabel standaard. Je hoeft ze niet
zelf toe te voegen.

## Voorbeeld

```js
import { VlDataTable } from '@domg-wc/data-visualisation';
```

```html
<vl-data-figure>
    <vl-chart-line></vl-chart-line>
    <vl-data-table></vl-data-table>
</vl-data-figure>
```

## Gebruik

- De tabel heeft een kolom per reeks en een rij per x-waarde.
- Een ontbrekende meting wordt als een lege cel getoond, nooit als 0. Boven de tabel wordt uitgelegd wat een lege cel
  betekent.
- Voeg je zelf een `vl-data-table` toe aan de figuur, dan wordt de tabel op die plaats getoond.

## Toegankelijkheid

- De tabel kan niet weggelaten worden (WCAG 1.1.1).
- Een schermlezer leest bij elke cel de reeks en de x-waarde voor.
